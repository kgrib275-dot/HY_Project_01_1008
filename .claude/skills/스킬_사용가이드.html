설치 방법

필요한 것: Claude Code, Python 3 (패키지는 Claude가 필요할 때 알아서 설치합니다)

A. 이 프로젝트에서만 쓰기 — 저장소를 받기만 하면 됩니다.

  1. 저장소를 받고 그 폴더로 이동합니다. 
    git clone https://github.com/kgrib275-dot/HY_Project_01_1008.git
cd HY_Project_01_1008
  2. 그 폴더에서 claude를 실행하고 /를 입력해 스킬 3개가 보이는지 확인합니다.

B. 모든 프로젝트에서 쓰기 (내 PC 전역 설치)

  1. git pull로 최신 상태를 받습니다.
  2. .claude/skills/sync_to_global.bat을 더블클릭합니다.
  3. Claude Code를 새로 시작하고 /로 확인합니다.

스킬이 업데이트되면 git pull 후 2번을 다시 실행하면 됩니다.

안 보이면: ① 저장소 폴더가 아닌 곳에서 실행했는지(A 방식) ② 이미 켜 둔 창은 종료 후 재시작 — 스킬 목록은 시작할 때 한 번만 읽습니다.

주의

  • 수정은 항상 저장소의 원본에서 합니다. 전역 복사본은 다음 동기화 때 덮어써집니다.
  • 결과물 폴더는 git에 올라가지 않습니다. 다른 프로젝트에서 쓸 때는 그 프로젝트의 .gitignore에도 넣으세요. (회의록에 고객 정보가 들어갈 수 있습니다)
  • 생성된 파일을 Word · PowerPoint에서 직접 열어 확인하지는 못했습니다. 글자 넘침이 있을 수 있으니 처음 쓸 때는 열어서 확인해 주세요.
