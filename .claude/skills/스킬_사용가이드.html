팀 공용 Claude 스킬 가이드

제안서 · 화면설계서 · 회의록을 팀 표준 양식으로 만들어 주는 스킬 3종의 설명과 설치 방법입니다. (작성 기준일 2026-10-15)

스킬이란 스킬 3종 설치 방법 사용 방법 수정 · 업데이트 문제 해결 알아 둘 점

1. 스킬이란?

스킬은 SKILL.md 파일이 들어 있는 폴더입니다. 프로그램을 설치하는 것이 아니라, Claude에게 주는 작업 매뉴얼 + 양식 파일 + 보조 스크립트 묶음입니다.

  1. 등록 (자동) — Claude Code는 시작할 때 .claude/skills/*/SKILL.md를 읽어 각 스킬의 이름과 설명(description)을 목록에 올립니다. 별도 등록 명령은 없습니다.
  2. 호출 — /스킬이름 내용처럼 직접 부르거나, “회의록 만들어줘”처럼 말하면 설명이 맞는 스킬을 Claude가 불러옵니다.
  3. 실행 — 호출되면 SKILL.md 전체가 로드되고, Claude가 그 지침대로 양식 파일과 스크립트를 사용해 결과 파일을 만듭니다.
핵심 규칙: 스킬은 두 곳 중 한 곳에 있어야 보입니다. ① 열어 둔 프로젝트의 .claude/skills (그 폴더에서 실행할 때만), ② 내 PC 전역 ~/.claude/skills (어느 폴더에서든). Claude Code는 시작할 때 한 번만 목록을 읽으므로, 스킬을 추가·수정한 뒤에는 새로 시작해야 합니다.

2. 스킬 3종

proposal_01

제안서PPTX 70p

프로젝트 내용을 표준 제안서 양식에 맞춰 채웁니다. Ⅰ 제안 배경 → Ⅵ 부록 구성이며 전체(70p) 또는 요약형(15~25p)으로 만듭니다.

UIWireframes_01

화면설계서PPTX 50p

화면 목록과 기능을 표준 화면설계서(와이어프레임 + 번호 설명표 + 정의서)로 만듭니다. 제안서와 같은 ID 체계를 씁니다.

MeetingNote

회의록Word + HTML

녹취록·메모를 7개 섹션 표준 회의록으로 정리해 같은 서식의 .docx와 .html 두 파일을 만듭니다.

proposal_01 — 제안서

입력사업 · 프로젝트 내용(메모, 데이터, 이 저장소의 프로젝트 내용). 고객사 · 제안사 · 작성자 · 날짜 · 현황 · 목표 · 범위 · 기능 · 일정 · 비용
호출 예/proposal_01 Trade IQ 프로젝트로 효성 무역PG 대상 요약형 제안서 만들어줘
동작입력을 표로 요약해 확인받음 → 슬라이드 선택 · 번호 재정리 → 양식의 텍스트만 교체(디자인 유지) → 검증
결과물proposals/[고객사]_[사업명]_제안서_YYYYMMDD.pptx
주의입력에 없는 수치는 만들지 않고 [N%] · [000] 자리표시자로 남깁니다. 마지막 보고의 “미확정 항목”을 직접 채워야 합니다. 양식 속 예시 문장은 “사내 AI Assistant” 사업 기준이라 다른 성격의 사업이면 대부분 새로 씁니다.

UIWireframes_01 — 화면설계서

입력서비스 설명, 화면 목록(화면명 · ID · 유형 · 대상 · 연결 기능), 메뉴 구조, 역할, 화면별 요소와 동작 규칙
호출 예/UIWireframes_01 Trade IQ 화면 목록으로 화면설계서 만들어줘
동작화면 유형에 가까운 원본 페이지(로그인 · 목록 · 폼 · 대시보드 · 팝업 · 모바일 등)를 골라 와이어프레임 속 텍스트와 번호 설명표를 교체
결과물wireframes/[서비스명]_화면설계서_YYYYMMDD.pptx
주의도형 위에 글자가 올라가는 구조라 글자 넘침 확인이 중요합니다. 새 화면 생성은 아직 끝까지 시험해 보지 않았습니다. 처음 쓸 때는 결과를 꼭 PowerPoint에서 열어 확인하세요.

MeetingNote — 회의록

입력녹취록 · 메모 · 전사 텍스트(붙여넣기 또는 파일 경로). 일시 · 장소 · 참석자 · 작성일이 없으면 먼저 묻습니다.
호출 예/MeetingNote 아래 녹취록으로 회의록 만들어줘 …
/MeetingNote 오늘 회의록 양식을 내용 비우고 뽑아줘 (빈 양식)
구성1 회의 개요 · 2 회의 목적 · 3 주요 논의 내용 · 4 결정 사항 · 5 Action Items · 6 리스크 및 이슈 · 7 확인 필요 사항 (값이 없는 섹션은 빠지고 번호 자동 재정렬)
결과물meetings/회의록_YYYYMMDD.docx + .html (저장 폴더를 지정하면 그곳에)
원칙말하지 않은 내용은 만들지 않음 · 개조식 · 발화자 이름이 없으면 소속/역할 기준 · 추정한 담당/기한은 7번에 “확인 필요”로 명시

3. 설치 방법

팀원에게 필요한 것은 Claude Code와 Python 3입니다. 설치 방식은 두 가지이며, 함께 써도 됩니다.

방법 A. 저장소로 받기 — 이 프로젝트 폴더에서만 사용

스킬이 저장소에 들어 있으므로 받기만 하면 됩니다. 별도 설치 작업이 없습니다.

  1. 저장소를 받습니다. (처음이면 git clone, 이미 있으면 git pull) 
    git clone https://github.com/kgrib275-dot/HY_Project_01_1008.git
cd HY_Project_01_1008
  2. 그 폴더에서 Claude Code를 실행합니다. 
    claude
  3. /를 입력해 proposal_01 · UIWireframes_01 · MeetingNote가 보이는지 확인합니다.
홈 폴더(예: C:\Users\이름)에서 실행하면 보이지 않습니다. 스킬이 저장소 폴더 안에 있기 때문입니다. 이미 켜 둔 창이면 종료 후 다시 시작하세요.

방법 B. 내 PC 전역에 설치 — 모든 프로젝트에서 사용

스킬을 ~/.claude/skills(Windows: C:\Users\이름\.claude\skills)로 복사해 두면 어느 폴더에서 실행해도 보입니다. 동기화 스크립트가 이 복사를 대신합니다.

  1. 방법 A의 1번처럼 저장소를 받아 둡니다(git pull로 최신 상태 유지).
  2. .claude/skills/sync_to_global.bat을 더블클릭합니다. (명령줄이면 python sync_to_global.py)
  3. Claude Code를 새로 시작하고 아무 폴더에서나 /를 입력해 확인합니다.
명령의미
python sync_to_global.py3개 스킬 모두 동기화
python sync_to_global.py MeetingNote지정한 스킬만
python sync_to_global.py --dry-run바뀔 내용만 표시(실제 복사 안 함) — 먼저 확인할 때
안전장치: SKILL.md가 있는 폴더만 복사하고, 전역 폴더의 다른 스킬은 건드리지 않으며, 같은 이름의 비(非)스킬 폴더가 있으면 덮어쓰지 않고 건너뜁니다. 원본에서 지운 파일은 복사본에서도 지워집니다.
스크립트 없이 직접 복사하려면 (PowerShell) 
Copy-Item -Recurse .claude\skills\proposal_01     $HOME\.claude\skills\
Copy-Item -Recurse .claude\skills\UIWireframes_01 $HOME\.claude\skills\
Copy-Item -Recurse .claude\skills\MeetingNote     $HOME\.claude\skills\

이 방식은 이후 수정사항이 자동으로 따라오지 않고, 원본에서 지운 파일도 남습니다. 동기화 스크립트를 권합니다.

4. 사용 방법

  1. /스킬이름 뒤에 내용(텍스트 붙여넣기 · 파일 경로)을 함께 입력합니다.
  2. Claude가 빠진 정보를 묻고, 입력을 표로 요약해 확인을 받습니다.
  3. 확인 후 파일을 만들고, 경로 · 생략한 부분 · 미확정 항목을 보고합니다.
  4. 결과 파일을 열어 확인하고 필요한 부분을 알려 주면 해당 부분만 고칩니다.
스킬기본 저장 위치(실행한 프로젝트 기준)
proposal_01proposals/
UIWireframes_01wireframes/
MeetingNotemeetings/ (폴더를 지정하면 그곳)
보안: 이 폴더들은 이 저장소의 .gitignore에 들어 있어 git에 올라가지 않습니다. 전역 설치로 다른 프로젝트에서 쓸 때는 그 프로젝트의 .gitignore에도 proposals/ wireframes/ meetings/를 넣어 두세요. 회의록에는 고객 · 계약 정보가 들어갈 수 있습니다.

5. 수정 · 업데이트

  • 항상 원본(저장소의 .claude/skills)에서 고칩니다. 전역 복사본을 직접 고치면 다음 동기화 때 원본으로 덮어써집니다.
  • 고친 뒤: sync_to_global.bat 실행 → Claude Code 새로 시작.
  • 팀에 반영: 스킬 파일만 골라 커밋·푸시 → 팀원은 git pull 후 (전역 설치를 쓰면) 동기화 스크립트를 다시 실행.
  • 양식(template.pptx · templates/)을 바꿀 때는 파일을 교체하고, 슬라이드 번호가 바뀌면 slide_map.md도 함께 고칩니다.
  • 프로젝트마다 다른 양식이 필요하면 폴더를 복사해 이름을 바꿉니다(예: proposal_02). 폴더 이름과 SKILL.md의 name: 값을 같게 맞추세요.

6. 문제 해결

증상원인 · 해결
/ 목록에 스킬이 안 보임① 저장소 폴더가 아닌 곳에서 실행했는지(방법 A) → 폴더 이동 또는 전역 설치(방법 B) ② 이미 켜 둔 창이면 종료 후 재시작 ③ 그래도 안 되면 /skills 화면을 확인
동기화 스크립트가 안 열림 / 오류python --version으로 Python 설치 확인. .bat이 막히면 명령줄에서 python sync_to_global.py 실행
패키지 설치 실패사내 보안 정책 · 권한 문제일 수 있음. Claude가 안내하는 pip install --user 패키지명을 직접 실행
“PPTX 편집 스킬이 없다”는 안내계정에 anthropic-skills:pptx 스킬이 없는 경우. 파일은 만들어지지만 정리·검증이 빠지므로 PowerPoint에서 열어 확인
PPTX에서 글자가 넘치거나 겹침해당 슬라이드 번호를 알려 주면 문장을 줄여 다시 만듭니다 (폰트를 줄이지 않는 것이 원칙)
전역에서 고친 내용이 사라짐동기화가 원본으로 덮어쓴 것입니다. 수정은 원본에서 하세요

7. 알아 둘 점 (확인 상태)

확인한 것

  • MeetingNote: 기존 회의록을 입력으로 재생성해 원본과 서식 · 구조가 일치함을 확인
  • 제안서: 앞 10장, 요약형 25장을 생성하고 양식 검증을 통과함
  • 동기화 스크립트: 임시 폴더에서 신규 복사 · 변경 없음 · 되돌리기 · 충돌 방지 · 다른 스킬 보존을 시험

확인하지 못한 것

  • 생성된 .docx를 Word에서, .pptx를 PowerPoint에서 직접 열어 본 것은 아닙니다. 이 작업 PC에는 Word · PowerPoint · LibreOffice가 없어 화면 렌더링 · 글자 넘침을 확인하지 못했습니다.
  • 팀원 PC에서의 실제 호출 · 전역 설치 · 패키지 자동 설치
  • 데스크톱 앱 Code 탭 · IDE · 웹(claude.ai/code)에서의 동작 (같은 Claude Code라 될 가능성이 높지만 미확인). 웹 Code는 클라우드 환경이라 내 PC의 경로(C:\Users\…)를 읽을 수 없으니 내용을 붙여넣어야 합니다.
  • 일반 채팅(claude.ai 채팅 화면)은 프로젝트 폴더의 스킬을 읽지 않으므로 이 방식으로는 사용할 수 없습니다.
  • 전역 폴더와 프로젝트 폴더에 같은 이름의 스킬이 있을 때 어느 쪽이 우선하는지

처음 쓰는 팀원은 가벼운 입력으로 한 번 시험해 보고 문제가 있으면 공유해 주세요.
