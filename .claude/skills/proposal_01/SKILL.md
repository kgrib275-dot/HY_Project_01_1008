# proposal_01 — 표준 양식 제안서 생성

입력(데이터 · 메모 · 파일 · 이 저장소의 프로젝트 내용)을 받아 `template.pptx` 양식 그대로 내용을 채운 `.pptx`를 만든다.
양식의 디자인(레이아웃 · 색 · 폰트 · 도형 · 표 구조)은 바꾸지 않고 **텍스트만 교체**하며, 필요 없는 슬라이드는 삭제한다.

## 파일
- `template.pptx` — 원본 양식 (수정 금지, 항상 복사해서 사용)
- `slide_map.md` — 70장 슬라이드별 제목 · 형태 · 채울 내용. **작업 전 반드시 읽는다**
- `scripts/dump_text.py` — 슬라이드 텍스트 덤프. `--runs N`으로 슬라이드 N의 텍스트 인덱스를 본다
- `scripts/build_deck.py` — 슬라이드 선택 + 텍스트 교체 + 정리 + 검증을 한 번에 (사용법은 파일 상단 주석). 아래 3~4단계를 이 스크립트로 처리해도 된다
- PPTX 편집 도구(add_slide.py, clean.py, validate.py, 렌더링)는 `anthropic-skills:pptx` 스킬 것을 사용한다. 작업 시작 시 그 스킬을 로드한다.

## 사전 점검 (작업 시작 전에 매번 먼저 실행 — 필요한 것이 없으면 설치하고 진행한다)
1. `anthropic-skills:pptx` 스킬을 로드한다. 로드되지 않으면 사용자에게 "PPTX 편집 스킬이 없어 정리 · 검증을 생략한다"고 알리고, 결과물 보고에도 그 사실을 적는다 (`build_deck.py`는 이 경우 경고만 내고 생성은 계속한다).
2. 필요한 Python 패키지를 확인한다:
   ```bash
   python -c "import defusedxml" || pip install defusedxml
   ```
   - 권한 오류면 `pip install --user defusedxml`로 재시도한다
   - 이후 실행 중 `ModuleNotFoundError: No module named 'xxx'`가 나오면 **그 모듈을 `pip install xxx`로 설치하고 같은 명령을 다시 실행**한다 (예: `lxml`)
   - 설치가 끝내 실패하면 원인(권한 · 네트워크 · 사내 정책)을 사용자에게 알리고, 사용자가 직접 실행할 명령을 안내한다
3. 설치한 패키지가 있으면 최종 보고에 한 줄로 적는다.

## 절차

### 1. 입력 정리 (생성 전 사용자 확인)
입력에서 아래 항목을 뽑아 **표로 요약해 사용자에게 보여주고 확인**받는다. 비어 있는 핵심 항목은 질문한다.
- 고객사 · 제안사 · 작성자 · 제출일
- 사업명(제안서 제목) · 한 줄 슬로건
- 현황 · 문제 · 요구사항 / 목표 · KPI / 범위(In/Out)
- 핵심 기능 목록 · 사용자 · 시나리오
- 구축 방안(아키텍처 · 데이터 · 보안) / 일정 · 조직 / 비용
- 생성 분량: **전체(70p)** 또는 **요약형**(표지 · 요약 · 각 장 핵심 · 마무리, 약 15~25p)

입력에 없는 수치는 지어내지 않는다. 양식의 `[N%]`, `[000]` 같은 자리표시자를 그대로 두고 마지막에 "미확정 항목" 목록으로 보고한다.

### 2. 슬라이드 매핑
`slide_map.md`를 기준으로 각 슬라이드에 넣을 내용을 정한다.
- 입력 근거가 없는 슬라이드는 삭제 후보로 표시 (간지 · 표지 · 목차 · 마무리는 유지)
- 장을 삭제하면 목차(3), 문서 구성(2), 간지 번호가 맞도록 함께 고친다
- 제목 번호 체계(`Ⅰ-1.`, `Ⅱ-3.` …)는 삭제 후 연속되게 다시 매긴다
- 기능 ID(FN-xx) · 화면 ID · REQ ID는 슬라이드 간 일관되게 사용한다

### 3. 생성 (pptx 스킬의 템플릿 편집 방식)
```bash
# 작업 폴더는 스크래치패드 사용
python -c "import sys,zipfile; zipfile.ZipFile(sys.argv[1]).extractall('unpacked')" <skill>/template.pptx
# 슬라이드 삭제/순서 = ppt/presentation.xml 의 <p:sldIdLst> 편집 → clean.py
# 같은 형태 슬라이드가 더 필요하면 add_slide.py 로 복제 (구조 작업을 모두 끝낸 뒤 텍스트 편집)
# 텍스트 교체 = ppt/slides/slideN.xml 의 <a:t> 내용만 수정
```
- `<a:t>` 텍스트만 바꾸고 `<a:rPr>` · `<a:pPr>`(폰트 · 크기 · 색)는 유지한다
- 표 행이 부족하면 마지막 `<a:tr>`을 복제하고, 남으면 `<a:tr>`을 통째로 삭제한다
- 카드 · 단계 슬롯 수가 입력과 다르면 남는 슬롯의 도형 그룹을 통째로 삭제한다 (텍스트만 비우지 않음)
- 불릿 문단은 원본처럼 `•  ` 접두어 형식을 유지한다 (양식이 문자 불릿을 사용함)
- XML 처리 시 `defusedxml.minidom` 또는 문자열 치환 사용 (ElementTree 금지)
- 문체: 양식과 동일하게 명사형 · 간결체 (`~합니다`는 부제 문장에만), 한 줄에 들어갈 길이로 작성

### 4. 패키징 · 검증
```bash
(cd unpacked && rm -f ../out.pptx && zip -Xr ../out.pptx .)
python <pptx스킬>/scripts/office/validate.py out.pptx --original <skill>/template.pptx
python scripts/dump_text.py out.pptx | grep -E "\[고객사\]|\[제안사|YYYY|\bN\b|\[000\]"   # 남은 자리표시자 확인
```
- 렌더링 후 이미지로 텍스트 넘침 · 겹침을 확인한다 (pptx 스킬의 Visual QA). 넘치면 문장을 줄인다 — 폰트를 줄이지 않는다

### 5. 결과물
- 렌더링 도구가 없는 환경이면 글자 넘침을 확인하지 못했다는 사실을 사용자에게 알린다
- 저장 위치: 프로젝트 루트 `proposals/` 폴더, 파일명 `[고객사]_[사업명]_제안서_YYYYMMDD.pptx`
- 보고 내용: 파일 경로, 최종 장수, 삭제한 슬라이드, **미확정 자리표시자 목록(슬라이드 번호별)**
