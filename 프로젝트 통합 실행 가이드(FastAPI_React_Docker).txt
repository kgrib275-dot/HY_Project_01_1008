📦 [완벽 가이드] 프로젝트 통합 실행 및 환경 세팅 매뉴얼 (FastAPI + React + Docker)
본 매뉴얼은 파이썬이나 노드(Node.js) 등 복잡한 개발 환경을 개별로 구축할 필요 없이, Docker 하나만으로 전체 웹 애플리케이션을 완벽하게 구동할 수 있도록 작성되었습니다.

🛠️ 1단계: Docker Desktop 설치 및 초기 설정 (최초 1회)
컴퓨터에 도커가 설치되어 있지 않다면 아래 순서대로 설치를 진행해 주세요.

설치 파일 다운로드

Docker Desktop 공식 다운로드 페이지에 접속합니다.

운영체제에 맞는 파일(Docker Desktop for Windows 등)을 다운로드합니다.

프로그램 설치

다운로드한 인스톨러(.exe)를 실행합니다.

설치 중 옵션창이 나오면 기본값(Use WSL 2 features 등)을 유지한 채 OK 또는 Install을 눌러 끝까지 진행합니다.

PC 재부팅 및 구동 확인

설치가 완료되면 안내에 따라 컴퓨터를 재부팅합니다.

컴퓨터가 켜진 후 바탕화면이나 시작 메뉴에서 Docker Desktop을 실행합니다.

윈도우 우측 하단 작업표시줄(트레이 아이콘)에서 도커 고래 모양 아이콘에 불이 들어오고, 마우스를 올렸을 때 "Docker Desktop is running"이라는 문구가 뜰 때까지 잠시 기다립니다. (초기 실행 시 수 분이 소요될 수 있습니다.)

📁 2단계: 프로젝트 소스 준비
전달받은 압축 파일(.zip)을 원하는 경로(예: 바탕화면 또는 C:\DEV 등)에 압축 해제합니다.

압축을 풀면 생성되는 Project_01_1001 폴더 내부에 아래 구조의 파일들이 정상적으로 들어있는지 확인합니다.

backend/ (FastAPI 소스 코드 및 설정)

frontend/ (React 프론트엔드 소스 코드)

Dockerfile (통합 빌드 설정)

build.py (빌드 보조 스크립트)

🚀 3단계: 도커 이미지 빌드하기 (Build)
프로젝트의 프론트엔드와 백엔드를 도커 컨테이너 환경으로 통째로 패키징하는 과정입니다.

Project_01_1001 폴더 내부로 진입합니다.

폴더 상단의 경로 주소창을 클릭하고, 그곳에 cmd 또는 powershell을 입력한 뒤 [Enter]를 누릅니다. (해당 폴더 경로가 지정된 터미널 창이 열립니다.)

열린 터미널 창에 아래 명령어를 그대로 복사해서 붙여넣고 실행합니다.

Bash
docker build --no-cache -t project-01-app:latest .
확인 사항:

빌드가 시작되면 내부적으로 프론트엔드 리액트 빌드와 백엔드 파이썬 패키지 설치가 자동으로 진행됩니다.

중간에 에러 없이 naming to docker.io/library/project-01-app:latest 메시지가 뜨며 완료될 때까지 기다립니다. (약 1~2분 소요)

▶️ 4단계: 도커 컨테이너 실행하기 (Run)
빌드된 이미지를 바탕으로 실제 백그라운드 서버를 구동합니다.

동일한 터미널 창에서 아래 명령어를 입력합니다.

Bash
docker run --name project-01-container -p 8000:8000 project-01-app:latest

실행 성공 확인:

터미널 화면에 Uvicorn running on [http://0.0.0.0:8000](http://0.0.0.0:8000) 및 Application startup complete. 문구가 뜨면 정상적으로 서버가 켜진 것입니다.

💡 [참고] 자주 발생하는 에러 대처법
만약 실행 시 The container name "/project-01-container" is already in use라는 에러가 뜬다면, 이전에 실행했던 컨테이너가 남아있는 것입니다. 아래 명령어로 기존 컨테이너를 강제 삭제한 뒤 다시 실행해 주세요.

Bash
docker rm -f project-01-container
그 후 다시 docker run ... 명령어를 입력합니다.

🌐 5단계: 웹 서비스 접속하기
서버가 정상 구동되었다면 인터넷 브라우저(크롬, 엣지 등)를 엽니다.

메인 웹 화면 접속: 주소창에 아래 링크를 입력합니다.
👉 http://localhost:8000

API 백엔드 헬스체크:
👉 http://localhost:8000/api/health

🛑 관리 및 종료 방법
서버 임시 중지 (터미널 제어):

실행 중인 터미널 창에서 Ctrl + C를 누르면 서버가 멈춥니다.

컨테이너 완전 중지:

Bash
docker stop project-01-container
컨테이너 삭제:

Bash
docker rm project-01-container
