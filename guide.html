🛠️ 1단계: Docker Desktop 설치 및 초기 설정 (최초 1회)

컴퓨터에 도커가 설치되어 있지 않다면 아래 순서대로 설치를 진행해 주세요.

  • 설치 파일 다운로드: Docker Desktop 공식 다운로드 페이지에 접속하여 운영체제에 맞는 파일을 다운로드합니다.
  • 프로그램 설치: 다운로드한 인스톨러(.exe)를 실행하고 기본값(Use WSL 2 features 등)을 유지한 채 끝까지 진행합니다.
  • PC 재부팅 및 구동 확인: 설치 완료 후 컴퓨터를 재부팅하고, 작업표시줄 트레이 아이콘에 도커 고래 모양 불이 들어오며 "Docker Desktop is running" 상태가 될 때까지 대기합니다.

📁 2단계: 프로젝트 소스 준비

  • 전달받은 압축 파일 또는 작업 폴더를 원하는 경로(예: C:\DEV 등)에 위치시킵니다.
  • 폴더 내부에 아래 구조의 파일과 디렉터리들이 정상적으로 들어있는지 확인합니다.
backend/             # FastAPI 백엔드 소스 코드
frontend/            # React 프론트엔드 소스 코드
Dockerfile           # 통합 배포 빌드 설정
docker-compose.yaml  # 로컬 실시간 개발용 설정
build_docker.py      # 배포용 이미지 빌드 스크립트

💻 3단계: 실시간 개발 및 즉시 테스트 방법 추천 🚀

코드를 수정할 때마다 매번 도커를 다시 빌드할 필요 없이, 백엔드는 도커 볼륨 마운트로, 프론트엔드는 리액트 개발 서버로 띄워 실시간으로 화면과 API를 테스트합니다.

1. 백엔드 구동 (실시간 반영 적용)

  1. 프로젝트 최상단 폴더 경로에서 터미널(CMD 또는 PowerShell)을 엽니다.
  2. 아래 명령어를 입력하여 백엔드 컨테이너를 백그라운드로 실행합니다. (소스 코드가 볼륨 마운트되어 즉시 반영됩니다)
docker compose up -d
  • 💡 백엔드 코드(backend/ 하위 파일)를 수정하고 저장하면 --reload 옵션에 의해 서버가 자동으로 감지하고 반영합니다.

2. 프론트엔드 구동 (HMR 실시간 화면 반영)

  1. 터미널 창을 하나 더 엽니다.
  2. frontend 폴더로 이동하여 리액트 개발 서버를 실행합니다.
cd frontend
npm run dev
  • 💡 터미널에 안내되는 주소(예: http://localhost:5173)로 접속하여 App.jsx 등의 코드를 수정하고 저장하면, 브라우저 화면이 0.1초 만에 실시간으로 반영됩니다.

🚀 4단계: 최종 배포용 도커 이미지 빌드 및 테스트

개발이 완료된 코드를 최종적으로 하나의 도커 이미지로 완벽하게 패키징하여 테스트하는 과정입니다.

  1. 프로젝트 최상단 폴더로 이동하여 기존 실행 중인 컨테이너를 정리합니다. 
    docker compose down
  2. 배포용 이미지를 캐시 없이 새로 빌드합니다. 
    python build_docker.py
    (직접 명령어 빌드 시: docker build --no-cache -t kgrib275/hy-project:latest .)
  3. 빌드가 완료되면 통합된 컨테이너를 실행합니다. 
    docker compose up -d

서버가 정상 구동되었다면 인터넷 브라우저를 열어 아래 링크에 접속합니다.

🌐 메인 웹 서비스 접속 http://localhost:8000 🩺 API 백엔드 헬스체크 http://localhost:8000/api/health

🛑 관리 및 종료 방법

  • 로컬 개발 컨테이너 종료: 
    docker compose down
  • 포트 충돌(port is already allocated) 에러 대처법:
    이전에 실행된 컨테이너가 포트를 잡고 있는 경우 아래 명령어로 깔끔히 정리해 주세요. 
    docker stop $(docker ps -a -q)
docker rm $(docker ps -a -q)
